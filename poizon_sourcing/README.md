# POIZON 리셀 소싱 도우미

POIZON(得物) 셀러센터의 모델별 최저 판매가를 기준으로 수수료·배송비·목표 수익을 빼서
**최대 매입가**를 계산하고, 구글 쇼핑(한국, Serper.dev API)에서 그 가격 이하로 파는
**신뢰 쇼핑몰**(공식몰·백화점몰·정품 유통) 구입처를 찾아 목록(CSV)으로 만들어 줍니다.

> 네이버 쇼핑 검색 API는 2026-07-31부터 개발자센터 신규 키 발급이 중단되고 NAVER API HUB에도
> 제공되지 않아 기본 소스를 Serper로 바꿨습니다. 기존 개발자센터 키가 있다면 `--source naver`.

검색은 두 단계입니다: ① 구글 쇼핑 검색, ② 모델번호 웹 검색 후 신뢰몰 상품 페이지에서 가격·품절 여부를
직접 확인(의류처럼 구글 쇼핑에 모델번호로 안 잡히는 상품용, `--no-web` 으로 생략 가능).
롯데온·Hmall 등 일부 쇼핑몰은 자동 접근을 막아 가격을 읽지 못합니다.

구매처 필터: `trusted_malls.json` 의 `trusted` 목록(공식몰/백화점·대기업몰/정품 유통)만 결과에
남기고, `blocked`(쿠팡·G마켓·11번가 등 오픈마켓, 리셀/중고 플랫폼)는 항상 제외합니다.
목록에 없는 쇼핑몰까지 보려면 `--include-unverified`(등급 '미확인'으로 표시).

```
포이즌 최저가 ─▶ 정산금(수수료 차감) ─▶ − 배송비(입고·매입) ─▶ − 목표수익 = 최대 매입가
                                                         │
                       네이버 쇼핑 검색(모델번호, 가격 낮은 순) ─┴▶ 최대 매입가 이하 + 모델번호 일치 ─▶ deals.csv
```

## 1. 준비

1. **Serper.dev** 가입 → 대시보드의 API Key 확인 (가입 시 무료 크레딧 제공).
2. **수수료 설정**: `fees.example.json`을 복사해 셀러센터의 실제 카테고리별 수수료율,
   검수/서비스 비용, 검수센터 입고 택배비, 원하는 최소 수익으로 수정합니다.
   (예시 파일의 수수료 10% 등은 **실제 값이 아닙니다**.)
3. **포이즌 최저가 목록**: 셀러센터는 로그인이 필요해 자동 수집하지 않습니다.
   상품 검색 화면에서 관심 모델의 `상품 번호`와 최저가를 아래 형식의 CSV로 정리합니다
   (엑셀에서 "CSV UTF-8"로 저장). `₩82,000`처럼 기호·쉼표가 있어도 됩니다.

```csv
model_no,brand,name,poizon_price
JI0079,아디다스,아디다스 오리지널스 슈퍼스타 2 스니커즈,82000
```

## 2. 실행

```bash
pip install -r requirements.txt
export SERPER_API_KEY=발급받은키
python -m poizon_sourcing.find_deals my_products.csv --fees my_fees.json --out deals.csv
```

결과 `deals.csv` 컬럼: 모델번호, 상품명, 포이즌가, 최대 매입가, 국내 판매가, 예상 순수익,
수익률(%), 구매처 등급, 쇼핑몰명, 상품명, 구매 URL — 예상 순수익 높은 순.

## 3. 결과를 볼 때 꼭 확인할 것

- **사이즈별 가격**: 포이즌 목록의 최저가는 보통 *가장 싼 사이즈* 기준입니다. 국내에서 살
  수 있는 사이즈의 포이즌 가격을 다시 확인하세요.
- **같은 모델인지**: 상품명에 모델번호가 들어 있는 결과만 남기지만, 키즈/성인·컬러 차이는
  상세 페이지에서 확인해야 합니다.
- 검색 가격은 **배송비 제외**, 쿠폰·카드 할인 전 가격일 수 있습니다. 매입 배송비는
  `ship_from_shop` 으로 가정합니다. 구글 쇼핑 링크는 상품 비교 페이지로 연결될 수 있습니다.
- **정품·새상품**: 중고/리퍼/렌탈 등 키워드는 제외하지만, 포이즌 검수 탈락(정품 의심, 박스
  손상, 택 누락) 시 반송비와 시간 손실이 발생합니다. 공식몰·백화점몰·공식 스토어 우선.
- 가격은 수시로 바뀌므로 **구매 직전 포이즌 가격 재확인** 후 매입하세요.
