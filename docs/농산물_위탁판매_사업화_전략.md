# 농수산물 B2B 위탁판매 대화록 분석 및 사업화 전략

- 분석 대상: 카카오톡 오픈채팅 「과일위탁판매 B2B 농산물 수산물 축산물 농수산물」 대화록
- 기간: 2026-01-25 ~ 2026-11-05 (284일, 17,642줄)
- 작성일: 2026-11-05

---

## 1. 한 줄 요약

이 방은 **농업회사법인 공급사 1곳이 위탁판매 셀러 수천 명에게 공지를 일방향으로 뿌리는 방송 채널**입니다. 공급사의 주문량은 10개월 사이에 **하루 1.3만 건(6월)에서 1.6만~2.3만 건(10월)**으로 늘었습니다. 하지만 운영은 여전히 **카카오톡 공지, 구글 시트, 외부 어드민 사이트**에 기대고 있어서, 품절·단가 변동·미출고 정보가 셀러에게 늦게 전달되는 구조적 문제가 있습니다.
**사업 기회는 "상품을 더 파는 것"보다 "셀러와 공급사 사이의 정보 흐름을 자동화하는 것"에 있습니다.**

## 2. 대화록에서 확인한 사실 (데이터)

### 2-1. 채널 구조

| 항목 | 수치 | 해석 |
|---|---|---|
| 공급사 게시글 | 1,067건 | 대화는 사실상 공급사 혼자 함 (셀러 발언 0건) |
| 봇 메시지 | 594건 | 시트·어드민·문의 링크를 똑같이 반복 게시 |
| 입장 / 퇴장 | 1,354 / 1,118 | 들어온 인원의 83%만큼 나감 → **셀러 이탈이 큼** |
| 월별 신규 입장 | 1월 33 → 8월 213 (최대) → 10월 143 | 여름 성수기에 셀러 유입 최대 |
| 공급사 상품코드 | 40종 이상 (`제휴C-01` 474회, `N14` 175회, `제휴GSB-05` 146회 …) | 생산자 수십 곳을 묶어 파는 **애그리게이터** 모델 |

### 2-2. 공지 유형 (무엇을 가장 많이 알리나)

| 태그 | 횟수 |
|---|---|
| ★특가★ | 70 |
| ★단가인상★ | 65 (+ 단가조정·인상 등 변형 다수) |
| ★품절★ / 즉시·일시·긴급품절 | 63 / 14 / 7 / 2 |
| ★신규상품★ | 53 |
| '품절'이 들어간 줄 | 284 |

→ 공지의 대부분이 **가격과 재고 변동**입니다. 셀러는 이 내용을 자기 스마트스토어·쿠팡 상품에 **손으로 반영**해야 하고, 늦으면 품절 상품이 팔리거나 오른 가격을 반영하지 못해 손해를 봅니다.

### 2-3. 운영 방식

- **발주 마감 시각이 계속 바뀜**: 09:00 → 09:30 → 10:00 → 10:30 → 10:00 (10월, 주문 폭증 때문). 취소 마감은 별도.
- **결제**: 예치금을 미리 충전하는 방식. 3월에 대표자 개인 계좌에서 법인(농협) 계좌로 바뀜 → 이때부터 법인으로서 운영을 정식화.
- **등급제 가격**: VIP / VVIP / SVIP 코드와 물량별 할인 (일 100건 / 200건 / 500건 / 1,000건 이상이면 개별 단가 협의).
- **CS 정책**: 수령 후 3일 안에 양식으로 접수. 한파로 인한 냉해, 도서산간, '가정용' 등급은 CS 불가.
- **반복되는 운영 문제**: 미출고 안내, 어드민 상품 비노출·점검(설·단가 정리·리뉴얼 때마다), 송장 번호 변경, 같은 주문에 대한 중복 문의로 CS 지연.
- **판매 채널 공개 예고(4월)**: "공급업체 정보 · 원가 · 판매가를 상품 리스트에 공개" → 원가를 공개해 셀러의 신뢰를 얻겠다는 전략.

### 2-4. 시즌별 주력 품목 (언급 횟수 기준)

| 시기 | 주력 품목 |
|---|---|
| 1~2월 | 만감류(한라봉·천혜향·레드향), 감귤, **설 선물세트**, 카다이프·두바이쿠키(유행 상품, 2월 한정) |
| 3~4월 | 참외, 토마토, 사과, 망고, 포도 |
| 5~7월 | **복숭아(6월 184회)**, 수박, 자두, 참외, 옥수수, 매실 |
| 8~9월 | 수박, 샤인머스켓, 홍로사과, 배, **추석 선물세트(9월 51회)** |
| 10~11월 | 감귤(10월 67회), 사과, 밤, 고구마, 단감, 절임배추 |

→ **명절(설·추석)과 여름 복숭아·수박 시즌**이 매출의 정점입니다. 유행 상품(카다이프)은 한 달짜리입니다.

### 2-5. 가격 수준

- 대화록에 나온 공급가 443개의 중앙값은 **10,200원**, 사분위 범위는 **7,400 ~ 14,600원**입니다.
- 예: 가성비 레드향 3kg 12,300원 / 노지감귤 대과 5kg 12,000원 / 샤인머스켓 2kg 6,900원 / 참외 10kg 13,300원.
- 하루 1.6만~2.3만 건에 중앙값 단가를 곱하면 **공급사 일 거래액은 공급가 기준 약 1.6억~2.3억원으로 추정**됩니다. (주문 건수로 가중한 값이 아니므로 대략적인 규모로만 보세요.)

                       │  카톡 공지 / 구글시트 / 어드민            │ 수동 반영

| 대상 | 문제 | 근거 |

## 4. 추천 전략: 3단계 사업화

> **핵심 판단**: 처음부터 공급사와 경쟁(소싱·물류 투자)하는 것은 자본과 시간이 많이 듭니다.
> **① 셀러로 직접 들어가 현장을 배우고 현금을 만들면서 → ② 그 과정에서 겪은 문제를 해결하는 도구를 만들어 팔고 → ③ 쌓인 데이터와 셀러 네트워크로 직접 소싱하는** 순서를 추천합니다.

### 1단계 (0~3개월): 데이터 기반 위탁 셀러 — "현금 + 현장 학습"

**목표**: 재고 없이 매출을 만들고, 어떤 품목·가격대가 팔리는지 직접 확인합니다.

1. **품목 선정 기준** (대화록 분석 결과 활용)
   - 품절이 적고 출고가 안정적인 상품코드 위주 (미출고 공지에 자주 나오는 코드는 제외)
   - CS 가능한 등급(정품·특품) 위주. '가정용'은 CS가 불가하므로 리뷰 관리에 위험
   - 지금(11월) 시즌 품목: **감귤, 부사사과, 단감·대봉감, 고구마, 절임배추(김장)**, 그리고 1월 **설 선물세트** 사전 준비
2. **채널**: 스마트스토어 + 쿠팡 2채널로 시작합니다. 선물세트는 기업 단체주문(B2B 특판)도 함께 공략합니다.
3. **수익 구조 예시** (가정이며, 실제 수수료·택배비는 채널과 계약 조건을 확인해야 합니다)

   | 항목 | 금액 |
   |---|---|
   | 공급가 (노지감귤 대과 5kg) | 12,000원 |
   | 판매가 (가정) | 17,900원 |
   | 오픈마켓 수수료 (약 6~11%로 가정) | 약 1,100 ~ 2,000원 |
   | 광고비 (판매가의 10%로 가정) | 약 1,800원 |
   | **건당 이익** | **약 2,100 ~ 3,000원 (12~17%)** |

   → 하루 100건을 넘기면 공급사의 **물량별 할인(일 100건 이상 개별 단가)**을 받을 수 있어 마진이 개선됩니다. 목표: **3개월 안에 하루 100건**.
4. **공급사 의존도 줄이기**: 같은 품목을 다루는 공급사를 2~3곳 확보해 둡니다 (품절 시 대체, 단가 비교).

**핵심 지표(KPI)**: 하루 주문 건수, 건당 순이익, 품절 상품 판매로 인한 취소율, 리뷰 평점

### 2단계 (3~9개월): 위탁 셀러용 자동화 SaaS — "본업"

1단계에서 직접 겪는 가장 큰 문제(공지를 손으로 반영하는 일)를 해결하는 도구입니다.

**제품 이름(가칭)**: 공급사 공지 → 내 스토어 자동 동기화 서비스

| 기능 | 해결하는 문제 | 우선순위 |
|---|---|---|
| **공지 자동 파싱**: 카톡 공지와 구글 시트에서 `품절 / 단가인상 / 인하 / 신규 / 재오픈`과 상품코드를 추출 | 수동 확인 | MVP |
| **품절·단가 알림**: 내 등록 상품과 연결해 바뀐 항목만 푸시 (카카오 알림톡·텔레그램) | 품절 판매, 역마진 | MVP |
| **스토어 자동 반영**: 스마트스토어·쿠팡 API로 품절 처리와 판매가 수정 (마진율 규칙 기반) | 반영 지연 | 2차 |
| **발주 마감 타이머 / 발주서 자동 변환**: 공급사 양식에 맞춰 엑셀 생성, 도서산간 주문 자동 분리 | 마감 놓침, 도서산간 클레임 | 2차 |
| **미출고·송장 추적**: 송장 미입력이나 지연 주문을 감지하고 고객 안내 문자 템플릿 제공 | 고객 CS | 3차 |
| **시즌 캘린더 / 품목 추천**: 이 문서 2-4의 시즌 데이터로 다음 달 소싱 추천 | 품목 선정 | 3차 |

**가격**: 월 2만~5만원 구독 (연결할 수 있는 상품 수에 따라 단계별 가격)
**첫 고객**: 이런 위탁판매 방에는 셀러가 수천 명 있습니다 (이 방에만 10개월 동안 1,354명 입장). 1단계에서 직접 쓰면서 만든 사례로 **커뮤니티 안에서 입소문**을 냅니다.
**B2B 버전 (공급사용)**: 공급사에게는 "공지 작성·배포 자동화 + 셀러용 실시간 재고 API + CS 접수 폼"을 팝니다. 이 공급사처럼 **하루 1만 건 이상인 공급사가 바로 타깃**이고, 셀러 이탈을 줄여 준다는 점이 판매 포인트입니다.

**기술 메모**: 이 저장소에는 이미 외부 데이터를 수집해 보여주는 웹앱(Flask)이 있으므로, 같은 구조로 수집 → 파싱 → 알림 파이프라인의 MVP를 빠르게 만들 수 있습니다. 카카오톡 대화는 내보내기 파일(.txt)을 올리는 방식으로 시작하고, 이후 구글 시트를 실시간으로 읽는 방식으로 확장합니다.

**핵심 지표(KPI)**: 유료 셀러 수, 월 구독 매출(MRR), 월 이탈률, 품절 상품 판매 감소율

### 3단계 (9~18개월): 직접 소싱 / 셀러 연합 공급 — "규모화"

- 2단계 SaaS에 쌓인 **"어떤 품목이 언제 얼마에 몇 건 팔렸나" 데이터**로 잘 팔리는 품목만 산지와 직거래합니다.
- 셀러들의 주문을 모아 공급사에 **공동구매 단가(일 500~1,000건 기준)**를 협상합니다. 셀러는 더 싸게 사고, 우리는 수수료를 받습니다.
- 명절 선물세트는 **자체 브랜드(PB)**로 기업 특판 시장을 공략합니다 (설·추석 언급 급증 데이터 근거).

## 5. 리스크와 대응

| 리스크 | 내용 | 대응 |
|---|---|---|
| **공급 불안정** | 이상기후로 품절·지연이 잦음 (한파 냉해 CS 불가, 수산물 조업량 부족) | 공급사 다변화, 출고일 넉넉하게 설정, 시즌 초 품목은 예약판매로 |
| **가격 변동** | 단가가 "즉시적용"으로 바뀜 | 자동 동기화(2단계), 판매가에 변동 대비 마진 포함 |
| **품질 클레임** | '가정용' 등급은 CS 불가 → 리뷰 악화 | 정품·특품 위주로 판매, 상세페이지에 등급 기준을 명확히 표시 |
| **플랫폼 의존** | 카톡·오픈마켓 정책이 바뀌거나 API가 제한될 수 있음 | 공식 API 우선 사용, 알림 채널 여러 개 확보 |
| **법적 리스크 ⚠️** | 대화록에 **'리뷰용 상자'** 상품이 반복 등장 (1,690~1,850원). 빈 상자를 보내 리뷰를 만드는 용도라면 **전자상거래법·표시광고법 위반(허위·기만 리뷰)** 소지가 있음 | 이런 상품이나 방식은 **절대 쓰지 않음**. 리뷰는 체험단처럼 경제적 대가를 표시하는 합법적인 방식으로만 확보 |
| **공급사와 이해 충돌** | 셀러용 도구가 공급사 공지를 자동으로 수집하는 것을 공급사가 싫어할 수 있음 | 공급사용 B2B 버전으로 협력 관계를 만들고, 공식 데이터 제공을 제안 |

## 7. 다음에 확인할 것

1. 공급가에 **택배비가 포함되는지**, 박스·아이스팩 비용은 누가 내는지 (마진 계산의 핵심)
2. 공급사의 **셀러 계약 조건** (판매가 하한, 채널 제한, 상품 이미지 사용권)
3. 실제 판매 채널별 **수수료와 정산 주기**
4. 같은 품목을 다루는 **다른 공급사 2~3곳의 단가** 비교
5. 공급사 측에 B2B 자동화 도구를 쓸 의향이 있는지 (2단계 공급사용 버전 검증)
